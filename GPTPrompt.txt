5. AssessmentService.java was updated:
- Injects CodeExecutionService
- assignAssessment sets assignment.maxScore from assessment.maxScore
- Added executeAssignment(String assignmentId)

executeAssignment behavior:
- Only works for CODING_CHALLENGE
- Requires submittedCode
- Sets executionStatus RUNNING
- Calls codeExecutionService.executeCode(language, submittedCode, expectedOutput)
- Saves actualOutput and executionError
- If timeout:
  executionStatus = TIMEOUT
  score = 0
  feedback = Code execution timed out.
  status = GRADED
- If non-zero exit:
  executionStatus = ERROR
  score = 0
  feedback = Code execution failed. Check execution error.
  status = GRADED
- If output matched:
  executionStatus = PASSED
  score = maxScore
  feedback = Automatic grading passed. Output matched expected output.
  status = GRADED
- Else:
  executionStatus = FAILED
  score = 0
  feedback = Automatic grading failed. Output did not match expected output.
  status = GRADED
